# Derivative Damath - Project Overview

## Project Description
**Derivative Damath** is an educational mathematics board game built with Flutter that combines the traditional Filipino Damath game with calculus derivatives. Players move polynomial chips across an 8x8 board with arithmetic operations, computing derivatives to score points.

## Current Status
- **Completion**: ~40-45%
- **Platforms**: Android, iOS, Windows, Linux, Web

## What's Implemented
- Basic 8x8 game board with operation tiles (+, −, ×, ÷)
- Polynomial chips with superscript notation (e.g., 78x⁴)
- Basic movement and capture mechanics
- Home screen with PvC/PvP mode selection

## What's Missing (Key Gaps)
1. **Derivative Calculation Engine** - Core math feature
2. **Score Tracking System**
3. **AI Opponent** for Player vs Computer mode
4. **Win/Lose Detection**
5. **Dama Promotion**
6. **Multiple empty models and widgets**
