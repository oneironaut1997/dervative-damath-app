# Stakeholder Communication Plan

## Project Stakeholders

| Stakeholder | Role | Interest |
|-------------|------|----------|
| Developer | Primary | Build the application |
| Thesis Advisor | Oversight | Review progress and quality |
| End Users | Consumers | Students learning derivatives |

---

## Communication Channels

| Channel | Purpose | Frequency |
|---------|---------|----------|
| GitHub Issues | Task tracking, bugs | As needed |
| Code Reviews | Quality assurance | Per feature |
| Weekly Sync | Progress updates | Weekly |
| Documentation | Knowledge sharing | Per milestone |

---

## Meeting Schedule

### Weekly Standup
- **Duration**: 15-30 minutes
- **Format**: Async (via notes) or sync
- **Agenda**:
  1. What was completed
  2. What's planned next
  3. Blockers/risks

### Milestone Review
- **Frequency**: At each phase completion
- **Format**: Demo + documentation review
- **Participants**: Developer + Advisor
